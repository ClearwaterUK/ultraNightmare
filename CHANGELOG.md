## 1.1

- **Integrated Flazhik's UKEnemyIdentifier library**. Death markers will now indicate what enemy killed a player.
  - All death markers dropped prior to this update will not have a death cause shown.
  - Deaths where the mod was unable to ascertain the cause of death will display as "Unknown".
- Added config file options to disable/enable fetching of death markers, and sending of death markers to the server.
- Death markers now display the Steam username of the player they belong to. 
- Cheats are now force-disabled when beginning a run, if they were previously kept enabled.
- Alt/secret exits have been disabled.
